# 本云端任务浏览器验收记录（2026-10-22）

使用Chrome云端浏览器、隔离PG18.1和内存mock OSS，无真实云资源请求。

生成800×600网格PNG（100像素网格），原图坐标框用于人工/属性对照：

- 上传PNG → 100%视图拖动200×150框，属性为整数原图坐标。
- 移动框、逐一操作左上/右上/右下/左下控制点。
- 50%创建屏幕100×75框 → 原图宽200、高150；切至200%属性不变。
- 最终前后端版：200%视图平移后，移动屏幕40×20 → 原图增加20×10（101,101→121,111）。四角每次拖屏幕20像素，原图相应增减10像素，框从200×150依次为210×160、220×170、230×180、240×190。
- 将框拖向图外，X/Y钳制为0，宽高保持240×190。
- 删除→撤销→重做→撤销，列表及框数0/1正确。
- 点击保存到后端，收到确认后显示云端保存成功；图片库读出v2，重新打开原图与框。
- 导出包含原图的JSON→真实文件下载→重新导入，原图尺寸/坐标一致，可继续编辑并另存新图片。
- 保存后刷新恢复240×190框及原图；恢复不保留内存撤销栈。
- 未保存草稿切换到云端图片后，图片库仍显示独立草稿；重开草稿恢复原坐标。
- 开发中复现过上传失败，页面显示失败并保留本地草稿；修复后成功保存。后端故障注入覆盖OSS失败、DB上传/标注保存失败、409冲突，见integration.test.mjs。

JPEG/WebP、超限/无效图片、未认证、来源校验、DB版本、备份/恢复、迁移锁和回退由自动化API/隔离数据库测试覆盖。生产入口实际启动并验证health和静态网页；并非systemd/AL3实机验证。没有浏览器测试脚本调用真实RDS/OSS。
