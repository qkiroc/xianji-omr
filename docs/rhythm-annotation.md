# 小节与音符事件区域标注

在 Windows 项目根目录批量导入所有切图来源：

```powershell
.\import-localization-sources.cmd
# 只查看计划，不写入平台：
.\import-localization-sources.cmd --dry-run
# 只同步某个切图来源：
.\import-localization-sources.cmd --source 切图数据集UUID
```

默认平台是 `http://116.62.12.100:8790`，可通过 `--origin URL` 修改；复用本机 CLI 授权。
运行前检查线上 `/health` 的 schema 至少为 14，并核对数据集接口支持来源关联；旧版本直接停止，避免创建无来源的空数据集。
每个来源复用已有的 rhythm 数据集，没有时创建一个。仅导入已确认且包含六线谱、简谱或歌词区域的谱页；没有已确认页且尚未关联的来源跳过。
重复执行同步新增页，不覆盖已有标注，不自动生成或确认小节与事件框。不要同时启动多个导入进程。
执行报告保存在 `.artifacts/localization-import/latest.json`。中断或失败后保留已完成的导入，排除问题后重新运行即可。

在现有 `/localization/datasets` 中创建数据集并关联切图数据集。只导入已确认、包含六线谱 / 简谱 / 歌词区域的谱页，再次同步只补充新页。原图 SHA、来源谱行、歌曲分组及 train / val / test 划分固定保存。

本阶段只训练区域定位与分类：先在谱行中框选小节，再在小节中框选事件。六线谱和简谱的事件区域分为全音符、二分、四分、八分、十六分、三十二分六类；歌词只框选区域，不填写内容。事件框、横向锚点和小节上下文分别保留，坐标统一使用原图整数像素。

不标注事件类型、附点、连音、声部、延音关系、歌词文字或音符关联；小节也不填写拍号和时值合计。它们交给后续内容识别模型处理。基础类别仅描述区域类别，不代表已识别完整的实际音乐时长。

确认前检查选区有效、位于所属谱行 / 小节内，且音符事件已选择区域类别。每个来源谱行至少标注一个小节；歌词不要求文字、时值或关联关系。同一横坐标可以存在不同歌词行的区域。

| 快捷键 | 功能 |
| --- | --- |
| V / M / E | 选择 / 画小节 / 画事件 |
| 1–6 | 选择六类音符区域 |
| Tab | 原图与谱行裁片切换 |
| Ctrl/Cmd+S | 保存 |
| Ctrl/Cmd+Z | 撤销 |
| Ctrl/Cmd+Shift+Z；Ctrl/Cmd+Y | 重做 |
| Q | 删除选中事件或小节 |
| 方向键；Shift+方向键 | 移动 1；10 像素 |
| Enter | 确认并进入当前筛选下的下一页 |

未保存的新框支持删除和撤销；已保存框沿用永久删除流程。再次修改已确认选区会回到草稿。

## 导出

冻结已确认数据后下载 JSON 或裁片 ZIP。JSON 保留谱行、小节、事件区域及基础类别。ZIP 包含谱行、小节和事件裁片、局部选区坐标、锚点、上下文文件和原图映射，真值范围标为 `geometry-and-event-category`。

事件的 `rhythm` 字段仅保留 `duration`（1、2、4、8、16、32），表示基础区域类别；歌词为 `null`。保存和创建新快照时会去除上一版界面产生的内容字段，不会把它们作为本阶段的训练真值。

所有裁片继承来源歌曲的集合划分，不能随机拆分同一歌曲的裁片。沿用 localization CLI 的同步、冻结与下载接口。
