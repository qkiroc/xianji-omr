# 小节与时值标注

每条记录独立保存切图模型输出的谱行图片。新建数据集无需关联切图数据集；上传裁片即可标注。也可以把已有切图结果一次性复制到这里，后续修改或删除来源不会影响已复制的图片和标签。

旧数据在进入列表时自动转换为独立图片；已有小节和事件换算到裁片内坐标，取消原图附件与原图元信息。转换失败会回滚并保留旧记录。历史冻结快照保持原样。

## 编辑

在当前谱行中横向拖动划分小节，再在小节内横向框选事件。高度始终覆盖当前谱行，移动和缩放只改变左右边界。每个事件只有矩形框，没有可编辑中心线。

新增、删除、移动、缩放及修改时值都只编辑前端 JSON，可撤销或重做。删除已保存的框也不即时请求接口。保存提交整份 JSON，包含已删除的框；确认通过一次请求完成校验、保存和确认，失败不会先保存半成品。版本冲突或请求失败会保留本地草稿。

## 时值标签

- 基础时值：全、二分、四分、八分、十六分、三十二分。
- 附点：无附点、附点、双附点、三附点。
- 连音：三连音 3:2、五连音 5:4 等，支持自定义比例和分组。
- 选择连音比例后，可从当前事件起将后续相应数量的事件归为同组；也可选择已有分组。同一分组的比例必须一致。
- 音符和休止符分别标记，休止符不连接延音线。
- 延音线：无、起点、中间、终点。每个事件仍保留自身时值，延音标记表达跨事件的持续关系。
- 歌词只标区域，时值为 null。

以四分音符为 1 拍，实际时值等于基础拍数乘附点系数，再乘连音的正常份数 / 实际份数。八分音符三连音为 1/3 拍，附点八分音符为 3/4 拍；附点八分音符三连音为 1/2 拍。界面和导出使用约分后的整数分数，避免三连音浮点误差。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| V / M / E | 选择 / 画小节 / 画事件 |
| 1–6 | 基础时值，保留附点和连音设置 |
| . | 循环切换附点数量 |
| T | 切换三连音 |
| Q | 本地删除选中事件或小节 |
| 左右键 / Shift+左右键 | 左右移动 1 / 10 像素 |
| Ctrl/Cmd+S | 保存 |
| Ctrl/Cmd+Z | 撤销 |
| Ctrl/Cmd+Shift+Z / Ctrl/Cmd+Y | 重做 |
| Enter | 保存、确认并进入下一条 |

## 数据与导出

rhythm 标签使用 duration、可选 dots、kind: rest、tuplet: {actual, normal, groupId?}、tie: start / continue / stop。默认值省略，兼容已有仅 duration 的标签。无关的音高、歌词文本等不作为这个模型的训练目标。

JSON 快照为 omr-rhythm-snapshot-v2，裁片 ZIP 清单为 omr-rhythm-crops-v2，truth 为 geometry-and-rhythm。小节内事件及单事件标签完整保留上述时值信息，beats 字段为 {numerator, denominator}。坐标和映射只相对于独立裁片，不引用切图原图。

CLI 支持 localization datasets create（JSON 指定 task: rhythm）、localization crops import（JSON 包含 imageBase64、track、split、groupKey、可选 importKey）、localization datasets detach 和 localization datasets sync --source UUID。sync 是一次性复制来源结果，不建立数据依赖。重复的 importKey 不会重复写入图片。

批量导入脚本 import-localization-sources.cmd 要求服务端 schema >=16。旧记录转换和图片导入都使用独立对象，删除整个记录或数据集时一并清理对应图片。
