# 单页标注与复核工作流

数据集内按单张谱页分页展示。序号取 `pageOrder`，表示这页谱在所属歌曲中的第几页，和列表分页行号无关。搜索支持歌曲、文件名与来源，状态与集合筛选即时生效。

## 页面操作

- 编辑器顶部依次放置返回列表、歌曲与页码、上一页/下一页、保存和“确认并下一页”。AI 标记与改为草稿收进更多操作。
- 画框、选择、平移、缩放和撤销/重做放在独立工具栏。导入导出放在右侧页面设置中。
- 选中区域后，右侧仅显示该区域属性；Esc 或返回全部区域恢复页面配置。
- 原图加载中禁用编辑，失败提供重试。错误通过通知提示；队列处理完成使用普通信息提示。

## 队列与返回

进入编辑器时固定 `queue`：优先使用列表状态筛选，否则使用入口谱页的状态；历史未归类页面使用 `legacy`。翻页保留搜索、split 与 songId 筛选，使用列表的创建时间/ID倒序，末尾循环一次且排除当前页。

`GET /api/v2/datasets/:datasetId/pages/:pageId/neighbors` 返回 `previousPage`、`nextPage`（均为 `{id,songId} | null`）。锚点只要求仍属于当前数据集，不要求仍匹配状态，因此保存变成草稿、确认变成人工确认后仍可继续原队列。原 `previous`、`next` ID字段及 `nextUnconfirmed` 为旧客户端保留。

“确认并下一页”先保存修改，再提交人工确认，成功后进入原队列下一页。保存或确认失败均保留当前页；确认成功但导航失败会明确说明确认已完成，可以重试下一页。队列没有其他页面时停留并提示完成。

浏览器会话中按数据集与队列筛选保留最多100条已访问页面，上一页优先使用实际访问记录，因此能返回刚确认的谱页。这里只保存页面ID，不保存标注草稿。未保存切页仍通过统一的留在本页/放弃/保存后继续对话框处理；取消离开不写入访问记录。

## 编辑与数据删除

编辑器删除区域或小节不弹确认，只改变内存 JSON，保存前可撤销/重做。区域移动、删除、属性修改共用撤销历史；撤销到保存基线恢复干净状态，成功保存重置该页的撤销/重做。服务端 PUT 接受移除已保存的区域、小节和事件ID，保留并发版本校验。普通标注保存不删除原图、原始定位附件或冻结快照。

列表删除数据集、原图、定位记录和导出快照仍确认影响范围，并通过专用清理服务处理数据库与相关文件。参见[数据清理说明](permanent-deletion.md)。

本轮没有数据库迁移。自动化覆盖隔离 PostgreSQL、模拟 OSS、真实 React/Ant Design 控件和 Chromium 浏览器中的删除撤销、保存失败、同类队列、确认跳页、上一页与窄屏布局。

## 编辑器快捷键

Windows 使用 Ctrl，macOS 使用 ⌘；保存、删除、撤销和重做在原图标注与裁片预览中共用同一份标注和历史。

| 操作 | Windows | macOS |
| --- | --- | --- |
| 保存 | Ctrl+S | ⌘+S |
| 删除当前标记 | Q / Delete / Backspace | Q / Delete / Backspace |
| 撤销 | Ctrl+Z | ⌘+Z |
| 重做 | Ctrl+Shift+Z / Ctrl+Y | ⌘+Shift+Z / ⌘+Y |
| 切换原图 / 裁片 | Tab | Tab |

原图中先选中标记；裁片中悬停或聚焦卡片，彩色边框表示当前删除目标。删除不弹确认，保存前可撤销。按住删除键不会连续删除。输入框、可编辑文本、展开的下拉菜单和弹窗内不会触发标记删除；输入框中保留原生撤销与 Tab 行为。输入框内仍可使用保存快捷键。

## 更新时间与人工审核趋势

列表展示谱页最近更新时间，统一按北京时间显示。顶部人工审核趋势支持近7/30/90天，按北京时间自然日统计人工确认谱页，同一页同一天只计一次；跨日重新确认会计入当天工作量。趋势保留已完成的审核记录，后续编辑或撤回确认不会抹去历史。

趋势与复核数量共用搜索、歌曲和集合范围，独立于列表分页及复核状态筛选；无记录的日期补零。AI复核与合成批量确认不计入，网页手工审核合成谱页仍计入。历史确认页没有独立确认时间，因此schema8迁移仅将现有非合成确认页的更新时间回填为估算，图中单独提示。成功确认后记录准确日期，版本冲突或确认失败不记数。

新增schema8扩展迁移，为谱页保存按日去重的人工审核记录；旧标注内容、版本号及冻结快照均不改变，删除谱页时记录随谱页一并清理。
