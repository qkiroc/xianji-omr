# 编辑器配置与裁片页简化

- 页面内错误条、错误段落及几何校验提示统一由全局toast承载，保留可重试操作。支持关闭、10秒过期、重复消息去重、最多四条；相同消息更新不延长过期时间，关闭后不因父组件重渲染而反复弹出。问题框本身继续红框高亮。HTTP明文传输安全说明属于授权说明，保留常驻提示而不是隐藏为错误。
- 选中区域时，右侧仅包含该区域标题、类别、元信息、坐标/关联高级属性及返回页面配置入口。无选择时才显示新建类别、区域列表与页类型。类别按钮、选中区域标题和类别控件使用taxonomy已有颜色，不修改类别ID。
- 裁片移除原图总览、逐框复核状态与状态筛选、底部操作按钮和大图弹窗；只有标题、变调夹、调号、拍号使用小卡片，其余类别（包括歌手、BPM、和弦标记）占整行。点击图片按稳定框ID切回原图调整，保持类别筛选、预览尺寸、滚动位置和当前内存草稿。旧cropReview参数清除，避免隐藏数据。
- 保留可恢复删除入口、原图页确认、既有服务端区域review字段/API/CLI和历史导出快照；没有数据迁移或自动改写复核数据。预览仍按同一像素裁切规则读取当前草稿。

验证：npm run typecheck、npm run build、git diff --check；23项测试通过。新增实际裁片React组件服务端渲染测试（真实Next搜索参数上下文，检查布局、入口、移除内容及Capo0），以及toast队列生命周期测试；其余为画布、导航、几何、CLI与隔离PG/mock存储目录/裁片回归。服务端组件渲染不是浏览器E2E；toast实际DOM计时、鼠标/键盘及右侧配置切换尚未新增浏览器验收。当前云端浏览器已被URL策略阻断，不绕过、不声称视觉验收通过。未部署生产。
