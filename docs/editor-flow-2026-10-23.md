# 标注编辑器操作链整理

本轮围绕实际误操作点调整，不变更类别、坐标、持久化、API/CLI及确认语义。

1. 新建类别面板只决定下一个新框，选择类别即进入画框并清空当前选择；已有框通过选中后的“类别”属性修改。类别快捷键0–6使用同一入口。
2. 默认一次画框完成即回到选择调整；显式勾选“连续画框”后才保留画框模式。切换工具先结束当前手势，Esc取消当前手势并回到选择模式。定位编辑器画完小节框也回到选择模式；点击补事件仍可连续使用。
3. 选中时隐藏其他区域，保留既有要求；“显示全部框”、点击空白或Esc解除选择。区域列表点击按稳定ID定位并切到选择模式。
4. 普通滚轮平移，Ctrl/⌘滚轮围绕鼠标缩放；空格拖动临时平移。方向键按原图1像素、Shift方向键10像素微调，边界裁限，进入原有撤销栈。Ctrl/⌘Z撤销、Ctrl/⌘ShiftZ或Ctrl/⌘Y重做。
5. 两个编辑器均支持Ctrl/⌘S保存；保存确认保持服务端版本校验。明确点击确认并同意提示后才保存/提交，取消确认不顺带写入。保存忙碌时禁用确认操作。翻页/退出沿用保存/放弃/取消拦截，没有浏览器草稿持久化。
6. 画布快捷键避开输入控件、可编辑文本、弹窗和隐藏画布；按钮空格/回车保留原生激活。修正零尺寸/取消绘制后悬空选择，删除失效ID不会误删末尾区域。
7. 坐标及可选父谱行关联收进高级属性；谱行选项显示可读序号及位置，实际仍用稳定ID保存。新建类别、当前框属性及手势说明分开呈现。

验证：严格TS检查、生产构建、git diff --check；16项测试通过（新增5项直接实例化生产画布操作逻辑，覆盖画框/连续模式/取消/无效选择/边界微调/撤销重做/弹窗与隐藏保护/滚轮锚点/选中隐藏；其余11项为路由、定位坐标、CLI映射、隔离PG/mock存储裁片及目录回归）。这些画布测试使用受控DOM事件适配，不是实际浏览器E2E。浏览器环境此前已被URL策略拦截，本轮没有绕过限制，也没有把此结果宣称为浏览器验收。未操作生产。
