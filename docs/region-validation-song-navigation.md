# 问题区域高亮与歌曲切换

- 父谱行包含关系按服务端同样的包含边界实时检查。问题子框红色粗边与“!”编号，所属谱行橙色虚线；不存在/类型错误的父框也会标记子框。不会猜测父关系或修改坐标。页级无父元信息不强制关联。
- 选中正常框时仍显示问题子框与父谱行提示，以免隐藏错误；其他正常未选中框继续隐藏。上方错误提示可定位子区域或所属谱行，区域列表同步标记。修正、撤销和删除后从当前草稿重新计算。
- 编辑器顶部上一首/下一首按当前数据集活跃歌曲的服务端顺序（created_at,id）切换，不限当前表格页；不是按表格筛选后的歌曲序列。保留原筛选、页码与原图/裁片视图，清除旧框选择。进入目标歌曲第一张活跃谱页；空歌曲进入上传页。边界按钮禁用。
- 歌曲跳转调用既有导航guard，未保存的保存/放弃/取消语义不变。路由加载期间不再拿前一首歌曲做首谱页重定向，失效页面读取不再继续归一化/重定向。

验证：严格类型检查、Next生产构建、git diff --check；21项回归通过，包括新增父子边界/错误父级/修正消失、Canvas实际绘制调用的红框/感叹号/虚线父级断言、选中正常框不隐藏错误框、导航URL保留/清除状态与空歌曲；保留隔离PG/mock存储、CLI路由与裁片回归。受控Canvas事件及绘制测试不等于真实浏览器视觉验收；当前云端浏览器URL策略此前已拦截，本轮没有新的浏览器截图/导航guard端到端验收。不操作生产或真实数据。
